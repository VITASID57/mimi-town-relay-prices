# 棉棉云小镇 · 中转站价目

棉棉云小镇“中转站”比价用的公开价目表，每天北京时间凌晨 3 点自动更新一次。

- `data/prices.json`：小镇读取的价目表。单位为「元 / 百万 token」，按次模型为「元 / 次」。
- `sites.json`：参与比价的站点清单。只收国内常用、公开价目可以匿名读取的站。
- `scripts/`：抓取与换算脚本；`tests/`：解析规则的检查。

## 价格怎么算

- **各站价格**：读各站公开的 `/api/status`（充值比例）与 `/api/pricing`（模型与分组倍率）。每个模型取该站最便宜的可用分组，按「站内美元额度 × 充值比例」换成实际要付的人民币。
- **官方价**：取 OpenRouter 公开模型价目里模型厂商自己的条目（与官方原价一致），按当天汇率换成人民币。
- 充值比例读不到可信值时，价目表会标出「待核」，按 1 元买 1 美元额度估算。

## 站点上下架

- 某站某天读不到时，先沿用它上一次成功读到的价格，并标出日期。
- 连续 3 天读不到就自动下架；之后哪天能读到了，会自动回来。
- 只读取公开价目，不注册、不登录、不调用模型，也不保存任何账号信息。

站方希望更正或不再收录，请提 Issue。
